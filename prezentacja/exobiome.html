PROBLEM · CO I DLACZEGO
Otwarty problem astrofizyki

Czytamy skład atmosfery egzoplanety z jej światła

Gdy planeta przechodzi przed tarczą gwiazdy, gazy pochłaniają światło w swoich pasmach. To chemiczny odcisk palca. Z jednego zaszumionego, niskorozdzielczego widma trzeba wyprowadzić zawartości gazów - klasyczne zadanie odwrotne.

  • Cel: 5 zawartości gazów H2O · CO2 · CO · CH4 · NH3 (log-VMR)
  • Mówią o chemii, klimacie i potencjalnej zamieszkiwalności
  • Dane symulowane (Ariel Data Challenge 2023) - prawdę znamy
PROBLEM · WIDMO TRANSMISYJNE
Chemiczny odcisk palca

Każdy gaz pochłania we własnym paśmie

Zafalowanie pod znacznikiem gazu to ślad jego absorpcji. Pasmo wokół linii = szum pomiaru. Model uczy się odwzorować ten kształt na zawartości chemiczne.

OBSZAR A · LISTING 1 . STRATEGIA
A Ścieżka klasyczna vs kwantowa

Strategia zamiast if w forward()

models/hybrid_core/model.py
class PredictionBranchStrategy(ABC):
    @abstractmethod
    def apply(self, ctx: PredictionContext) -> torch.Tensor: ...

class ClassicalBranchStrategy(PredictionBranchStrategy):
    def apply(self, ctx):
        return ctx.classical_pred.float()

class QuantumBranchStrategy(PredictionBranchStrategy):
    def apply(self, ctx):
        angles = ctx.regressor.projector(ctx.fused)
        q     = ctx.regressor.quantum_block(angles)
        gate  = torch.tanh(ctx.regressor.quantum_gate)
        return ctx.classical_pred + ctx.quantum_scale * gate * q  # bramkowana korekta

Analiza: interfejs Strategii + dwie konkretne klasy - logika klasyczna i kwantowa zamknięte osobno. HybridArielRegressor nie musi znać szczegółów korekty kwantowej, co wzmacnia OCP.

OBSZAR A · LISTING 2 . ABC + FABRYKA
A Wspólny kontrakt + składanie

Polimorficzny forward(), jeden konstruktor

models/hybrid_core/model.py
class HybridRegressorBase(nn.Module, ABC):
    @abstractmethod
    def forward(self, aux, spectra, enable_quantum=True, quantum_scale=1.0): ...
    @abstractmethod
    def backbone_parameters(self) -> Iterable[nn.Parameter]: ...

class HybridArielRegressor(HybridRegressorBase):
    def forward(self, aux, spectra, enable_quantum=True, quantum_scale=1.0):
        fused, head_ctx, classical = self._compute_classical(aux, spectra)
        strategy = self._select_branch_strategy(enable_quantum, quantum_scale)
        return strategy.apply(PredictionContext(fused, head_ctx, classical, ...))

def build_model(config: ModelConfig, device) -> HybridRegressorBase:   # Fabryka
    return ClassicalOnlyHybridRegressor(...) if config.classical_only \
           else HybridArielRegressor(...)

OBSZAR B · LISTING 3 . HOF + DOMKNIĘCIE
B Kompozycja potoku

Domknięcie pamiętające scalery

app/data/pipeline.py
def pipe(*funcs: Func) -> Func:           # HOF: kompozycja lewo-do-prawa
    def run(value):
        return reduce(lambda acc, fn: fn(acc), funcs, value)
    return run                              # domkniecie nad `funcs`

def make_quantum_input(aux_scaler, spectral_scaler):
    aux_path = pipe(log_scale_aux,
                   lambda a: standardize_aux(a, aux_scaler))   # zamyka scaler
    spectra_path = pipe(to_channels_first, normalize_sample_spectra,
                       lambda s: standardize_spectra(s, spectral_scaler))
    def transform(rec: PlanetRecord):
        return aux_path(rec.aux), spectra_path(rec.spectrum)
    return transform

Analiza: pipe zbudowany na functools.reduce; make_quantum_input wstrzykuje scalery raz i zwraca bezstanowy potok. Cały przepis preprocessingu w jednym miejscu.

OBSZAR D · LISTING 4 . STRATEGIA + FABRYKA W UI
D Wymienne predyktory, jeden kontrakt

UI iteruje predyktory polimorficznie

app/ui/inference_adapter.py
class Predictor(ABC):                       # wspolny interfejs (Strategia)
    name: str
    @abstractmethod
    def predict(self, record: PlanetRecord) -> Prediction | None: ...

class RandomForestPredictor(Predictor):
    name = BASELINE_MODEL_NAME
    def predict(self, record): return rf_prediction(record)

class ClassicalHeadPredictor(Predictor):     # glowica klasyczna na zywo
    name = CLASSICAL_MODEL_NAME
    def predict(self, record): return self._engine.predict(record)

def build_predictors(engine) -> list[Predictor]:    # Fabryka
    return [RandomForestPredictor(), ClassicalHeadPredictor(engine),
            ReferenceQuantumPredictor(engine.checkpoint_dir)]

Analiza: predict() zwraca Prediction | None, więc UI iteruje predyktory bez if-ów per model. Nowy model = nowa klasa + wpis w fabryce (OCP); None = czysta rezygnacja, gdy brak danych kwantowych.

WNIOSKI · OCENA PARADYGMATU
Retrospektywa

Czy hybryda wniosła wartość dodaną?

ZALETY
  • Trafny wybór: zadanie ma dwie warstwy - stanowy proces vs bezstanowe transformacje
  • Testowalność: czyste funkcje i niemutowalne dane testujemy bez GPU i przeglądarki
  • Modularność: wymiana modelu/strategii bez zmian w reszcie systemu
OGRANICZENIA
  • Pokusa mieszania paradygmatów na styku z bibliotekami stanowymi (Streamlit, torch)
  • Wymaga dyscypliny trzymania efektów ubocznych na brzegu (I/O w jednym module)
  • Bez zbędnej złożoności: czysto imperatywne podejście splotłoby wybór modelu z renderowaniem

OOP uporządkowało proces i zależności, FP - transformacje danych. Paradygmaty się uzupełniają, nie kolidują.
